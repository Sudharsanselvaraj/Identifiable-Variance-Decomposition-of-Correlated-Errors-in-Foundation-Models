## 3. Data sources and redistribution

| Source | Licence | In this repository |
|---|---|---|
| `open-llm-leaderboard-old/details_*` (per-item MMLU predictions) | none declared ("More Information Needed") | **not redistributed**; regenerated by `scripts/download_ollb_v1.py` |
| `open-llm-leaderboard-old/contents` (metadata) | none declared | **not redistributed**; regenerated byte-identically by `scripts/fetch_v1_contents_meta.py` (SHA-256 checked) |
| MMLU (`cais/mmlu`) | MIT | not copied; item identities only |
| Hugging Face Hub model metadata (`base_model`, creation date) | Hub API | cached in `datasets/ollb/hub_meta.jsonl`, `config_lineage*.jsonl` |
| Kim et al. files in `datasets/kim/` | CC BY 4.0 | yes |

The public frozen lists (`datasets/ollb/frozen/*.csv`) omit the three fields
copied from the leaderboard metadata (type, architecture, parameter count).
`scripts/rebuild_frozen_lists.py` re-attaches them from the regenerated metadata
into `datasets/ollb/frozen_full/` and fails unless every file matches the SHA-256
recorded at freeze time. `v1_roster.csv` is regenerated by the roster builder.
A clean-room run on 2026-10-09 (all three inputs removed, then regenerated from
the public source) reproduced every input byte for byte and every reported
coefficient (pre-registered analyses to 1e-16; exploratory size/architecture
controls exactly; item-difficulty nulls byte-identical).

Exact private copies of these inputs, with hashes, sources and retrieval dates,
are kept outside version control (`private/exp04_input_snapshot/MANIFEST.json`).
Licensing status and decisions: `docs/release/LICENSING_NOTES.md`.

## 4. Reproduction steps (repo root)

```sh
python -m pip install -e ".[test,ollb]"
python scripts/fetch_v1_contents_meta.py          # leaderboard metadata (hash-checked)
python -m lineage_era.ollb.roster_v1              # roster (byte-identical to the analysed one)
python scripts/rebuild_frozen_lists.py            # full frozen lists; must match the frozen SHA-256
python -m lineage_era.ollb.hub_meta \
  --names datasets/ollb/v1_contents_meta.csv:fullname \
  --names datasets/kim/hugging_face.csv:name      # only if the cache is absent
python scripts/download_ollb_v1.py                # 977 validated answer files (~11 GB read)
python scripts/validation_report.py               # reconciled per-model categories
python scripts/run_exp04_final.py                 # 12 pre-registered analyses + audits; diffs vs committed outputs
python scripts/run_exp04_item_null.py             # item-difficulty-aware nulls (post hoc)
python scripts/run_pair_gate_audit.py --population primary --cap 40 --reps 500   # post-hoc gate audit
make -C paper tables && make -C paper             # tables from outputs, then the PDF
python -m pytest                                  # test suite
```
